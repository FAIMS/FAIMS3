# Display Fields

The **DISPLAY** tab contains field types for presenting static formatted
content and instructions within a form.

```{toctree}
---
caption: Display Fields
hidden: true
---

rich-text.md
parent-field-value.md

```

- **[RichText](rich-text.md)** — Displays formatted instructional content
  and headings within a form; does not capture data.
- **[Parent Field Value](parent-field-value.md)** — Displays a value from the
  parent record (read-only) while working in a child record; does not capture
  data.
